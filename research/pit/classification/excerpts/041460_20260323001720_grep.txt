 연구 배경 | 
 1. 경험기반 추론 기법에 의거한 사용자 자동문제 발견 및 정의 생성경험기반추론(Case-based Reasoning) 기반 사용자 상황 의도 및 문제 파악, 사용자 문제 파악 후 자동 문제 정의 수립

 3. 다중 에이전트(Multiple Agents)간 의사 소통 및 문제 협력 해결 지능형 개인 도우미가 복수의 여러 사용자를 분별하여 대응
 다자간 문제(사용자 그룹 공동 과제 등)를 상호 협력하여 조정 해결
 | 
 개발 목표 | 
 1. 3대 원천 기술 확보
 - Problem Solver로서의 Planner 개발
 - Case based Reasoning 알고리즘 개발
 - Memory Graph 알고리즘 개발 
 2. Conversational AI 구현을 위한 핵심 엔진 개발 3. Cloud API 서비스를 위한 엔진 가상화
 |

 연구 배경 |

 2. KISA 표준 공동인증서 저장 공간 (NPKI 폴더) 접근이 불가능하여, 기존 공동인증서 이용 고객에게 서비스가 불가능하
 3. 웹스토리지의 경우, 접속한 도메인에 대해서만 공동인증서를 사용할 수 있는 기술적 한계 극복 필요

 2. KISA 표준 공동인증서 저장 공간 (NPKI 폴더)을 접근하여 PFX 형태로 Expor, 웹스토리지에 저장 가능한 1회성 유틸리티 프로그램
