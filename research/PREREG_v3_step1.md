# v3 1단계 사전등록: 전략 비교 백테스트

작성 2026-11-05. **이 문서는 실데이터 결과를 보기 전에 커밋한다.** 결과를 본 뒤 아래 규칙·파라미터를 바꾸지 않는다.
바꿔야 하면 새 사전등록 문서를 만들고 이 문서와 결과는 그대로 남긴다.

## 질문

기존 단계 판정(C)이나 단순 순환 전략(D)이 단순 60일선 필터(B)보다 거래비용 차감 후에도 나은가.

## 공통 가정

| 항목 | 값 |
|---|---|
| 유니버스 | universe.json 28종목 (현재 생존 종목, 생존편향 있음) |
| 데이터 | 네이버 수정주가 일봉, 2015-01-01부터 수신 |
| 평가 기간 | **2016-01-04 ~ 마지막 거래일** (2015년은 지표 워밍업) |
| 바스켓 | 엔진의 ew_index: 그날 유효 종목 일간수익률 동일가중 평균 (매일 재조정 가정, 내부 재조정 비용은 모든 전략에 똑같이 무시) |
| 파트 지수 | 파트 소속 유효 종목 일간수익률 동일가중 누적. 파트 = 대형/전공정/후공정/기판/소재/테스트/부품 7개 |
| 신호 | 거래일 t 종가로 계산 |
| 체결 | **t+1 종가에 체결 → t+2 일간수익률부터 반영** (하루 통째로 늦게, 보수적) |
| 거래비용 | **편도 0.25%** (수수료·세금·슬리피지 합산 가정), 체결 금액 기준. 민감도로 편도 0.50%도 출력 (선택에 사용 안 함) |
| 현금 수익률 | **연 2.5%** 고정, 일할 복리 |
| 샤프 | (일간 순수익률 - 일간 현금수익률) 평균 / 표준편차 × √252 |

## 전략 (후보)

- **A 단순 보유**: 바스켓 100% 상시 보유
- **B 60일선**: 바스켓 누적지수 종가 > 그 60거래일 단순이동평균이면 바스켓 보유, 아니면 현금
- **C 단계 판정**: 엔진 phase == CONFIRMED(사이클확인)면 바스켓 보유, 아니면 현금 (v1·v2 단계 판정 동일)
- **D RS 1위 파트**: 매월 마지막 거래일 종가에 각 파트 지수의 **126거래일(약 6개월) 수익률** 1위 파트를 골라 다음 달 말까지 보유. 그날 유효 종목 2개 미만 파트는 제외. 상시 투자
- **D+B**: D가 고른 파트를 B 신호가 보유일 때만 보유, 아니면 현금 (B 신호는 매일 판정)

## 보조 (후보 아님, 참고 출력만)

- C2: phase가 EARLY 또는 CONFIRMED면 보유
- D63: D와 같고 모멘텀 기간만 63거래일
- 하닉 단순 보유
- 편도 0.50% 비용 민감도

보조 결과가 더 좋아도 이번 단계에서 채택하지 않는다.

## 출력

1. 전략별 CAGR, MDD(고점·저점·회복일), 샤프, 연간 회전율, 투자 비중(현금 아닌 날 비율), 비용 전·후 CAGR
2. 연도별 수익률, 시기별(2016~2018 / 2019~2022 / 2023~끝) 성과
3. 월별 구간: 바스켓 월 수익률 > +5% 상승월, < -5% 하락월, 그 사이 횡보월. 구간별 전략 평균 월수익률
4. **차이의 유의성**: 각 전략 vs B, vs A 의 일간 순수익률로 샤프 차이를 63거래일 이동블록 부트스트랩 2000회 (시드 42). P(차이 > 0)과 90% 구간. 겹치는 구간을 독립 표본으로 보지 않기 위해 블록 사용
5. **선택 walk-forward**: 2019년부터 매년 1월, 직전 3개 연도 순 샤프가 가장 높은 후보(A, B, C, D, D+B)를 골라 그해 그 전략 수익률을 그대로 받는다. 전략 갈아탈 때 비용은 무시(낙관적). 이 결과를 같은 기간 B와 비교
6. 실패 결과 포함 전부 research/results/ 에 보존

## 판정 기준 (미리 정함)

- "B보다 낫다" = 비용 차감 후 샤프 차이 부트스트랩 P(차이>0) ≥ 0.90 **그리고** MDD가 B보다 나쁘지 않음(B MDD - 5%p 이내)
- 이 기준을 넘어도 생존편향 때문에 **탐색 결과**로만 본다. 채택은 이후 데이터 검증 후
- B를 못 이기면: 해당 전략 규칙이 단순 추세 필터보다 나은 가치를 입증 못 한 것. 반도체 순환매 연구 전체의 실패를 뜻하지 않음

## 알려진 한계

- 생존편향: 2026년 기준 종목으로 과거를 재구성. 특히 D는 나중에 뜬 파트·종목이 과거에도 포함돼 과대평가 가능
- 유니버스가 시기마다 다름: 상장 전 종목은 빠짐 → 초기 파트는 종목 2~3개
- 동일가중 매일 재조정, 체결가 = 종가 가정
- 사이클 5개 수준이라 통계 검정력 낮음
