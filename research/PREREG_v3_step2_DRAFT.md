## 3. 반도체 관련사 판정 (시점별)

**근거 문서**: DART 사업보고서 「II. 사업의 내용」. 접수일부터 다음 사업보고서 접수일 전날까지 그 판정을 적용한다.
- 첫 사업보고서가 나오기 전 신규 상장사는 편입하지 않는다 (보수적, 시점 오염 없음)
- 분기·반기보고서는 쓰지 않는다

**후보 풀**
1. 2015-01-01 이후 KOSPI·KOSDAQ(GLOBAL 포함)에 상장됐던 보통주 전체 (marcap). 우선주·스팩·리츠·투자회사 제외
2. 1차 스캔: 회사별로 기간 내 첫 사업보고서와 마지막 사업보고서만 받아서 핵심어 합계 < 5 이면 제외 (스캔 부하 축소용)
3. 2차 스캔: 남은 회사의 기간 내 모든 사업보고서

**핵심어 (T1, 대소문자·띄어쓰기 무시)**: 반도체, 웨이퍼, 파운드리, 메모리, DRAM, 디램, NAND, 낸드, HBM, 팹리스

**판정 (보고서 1개 단위)**
- T1 합계 ≥ 20 → 반도체 관련 (자동)
- 5 ≤ T1 < 20 → 수동 검토. 기준: 반도체용 제품·서비스가 「주요 제품」 또는 매출 표에 별도 항목으로 있는가. 없거나 확인 불가면 `판정 보류` = 제외
- T1 < 5 → 제외
- 수동 검토 때 그 회사의 주가·수익률은 보지 않는다

## 4. 파트 배정

같은 사업보고서 「사업의 내용」에서 파트별 키워드 출현 수가 가장 많은 파트. 동점이거나 1위가 2위의 1.5배 미만이면 수동 검토(주요 제품 표 기준), 그래도 애매하면 `판정 보류` = 제외.

| 파트 | 키워드 (초안) |
|---|---|
| 대형 (칩 제조·설계) | 메모리, DRAM, NAND, HBM, 파운드리, 시스템반도체, 팹리스, 설계, 칩 |
| 전공정 | 증착, 식각, 세정, CVD, ALD, PVD, 노광, 이온주입, 열처리, 어닐링, 스트립 |
| 후공정 | 패키징, 본딩, 다이싱, OSAT, 어셈블리, 범핑, 몰딩, 리플로우 |
| 기판 | 패키지 기판, FC-CSP, FC-BGA, 반도체용 PCB, 서브스트레이트 |
| 소재 | 포토레지스트, 전구체, 프리커서, 식각액, CMP, 슬러리, 특수가스, 고순도 |
| 테스트 | 웨이퍼 테스트, 테스터, 검사장비, 테스트 소켓, 프로브카드, 핸들러, 번인 |
| 부품 | 쿼츠, 세라믹, SiC, 챔버 부품, 소모품, 링, 히터 |

- 키워드는 후보 탐색과 파트 배정용이며 단독 편입 근거가 아니다 (편입은 3절 T1 판정)
- 일반 PCB(서버·통신용 MLB)와 반도체 패키지 기판을 구분: '패키지 기판/서브스트레이트/FC-' 근거가 없으면 기판 파트로 넣지 않는다
- 사업이 바뀌면 그 사업보고서 접수일부터 파트가 바뀐다

**모든 판정은 `research/pit/classification.csv`에 남긴다**: 종목코드, 회사명, 보고서 접수번호(rcept_no), 접수일, T1 수, 파트별 키워드 수, 자동/수동, 판정, 파트, 사유.
현재 28종목도 같은 규칙으로 재심사한다 (예외 없음).

## 6. 출력

- 시점별 40종목 유니버스(T) vs 기존 28종목(F)의 A, B, D, D+B 성과, 부트스트랩, 사전등록 판정
- **D 성과 분해**: D(F) / D(T) / D(T∪F, 28종목 강제 포함) / D(T∩F, 겹치는 종목만)
  - D(F) - D(T∪F) = 덜 뜬 종목들이 들어와서 생긴 차이
  - D(T∪F) - D(T) = 28종목 중 그 시점엔 반도체 상위 40이 아니었던 종목을 미리 넣은 효과
- 연도별 D 수익에 가장 크게 기여한 종목 상위 5 (두 유니버스 각각)
- 상폐·합병 종목: 마지막 거래일 종가와 실제 합병 대가·잔여 재산 비교표 (가능한 것만)
- 유니버스 크기 추이, 파트별 종목 수 추이, `판정 보류` 수
- 보조: DART 대신 현재 KIND 주요제품 텍스트로 분류한 버전 (시점 오염 있음, 후보 아님)
